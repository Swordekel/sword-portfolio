dailytask.arswordlab.com

Started as a spreadsheet of daily tasks for a pet and aquarium shop. Now every staff member logs in to see only their own tasks for the day, ticks them off with a photo or video as proof, and a supervisor checks them. The admin edits the rolling four-week rota, with a balanced auto-assign.

Role
Full-stack: data model, API, auth, front end, notifications.
Built
  • Per-staff accounts; the server only returns the tasks a person does or supervises.
  • Photo and video proof, re-encoded in the browser and stored in R2.
  • Scheduled Web Push reminders from Cron Triggers.

About

I’m Sword Ekel, a full-stack developer from Jakarta. I study Cyber Security at BINUS University and work as a security analyst intern at PT Inti Siber Net.

Since 2025 I have built websites and web apps for clients under my own studio, ARSWORD, from the first sketch to a deployed site. I also run two products of my own: the studio platform and a point-of-sale system that a real shop uses every day. Security work taught me to read a site from the attacker’s side, so I ship with strict headers and keep secrets on the server.
