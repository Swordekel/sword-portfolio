ProductPoint-of-sale system2026

Point-of-sale system for food and drink outlets, in daily use at a real ice-cream shop.

A cashier app for Android tablets that keeps selling when the internet drops, an owner dashboard for sales, stock, staff and shifts, a QR menu for tables, and receipt and kitchen-ticket printing per station. Sold as a monthly subscription; the first outlet runs it every day.

Daily Task

ClientStaff scheduling app2026

Scheduling app for an animal shop’s staff: rotations, checks, photo proof and reminders.

Started as a spreadsheet of daily tasks for a pet and aquarium shop. Now every staff member logs in to see only their own tasks for the day, ticks them off with a photo or video as proof, and a supervisor checks them. The admin edits the rolling four-week rota, with a balanced auto-assign.

  • Per-staff accounts; the server only returns the tasks a person does or supervises.
  • Photo and video proof, re-encoded in the browser and stored in R2.
  • Scheduled Web Push reminders from Cron Triggers.
Role
Full-stack: data model, API, auth, front end, notifications.
Built with

  • Cloudflare Workers
